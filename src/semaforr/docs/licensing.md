# Licensing audit

`package.xml` declares `Apache-2.0`. No license, copyright, or provenance file
was present in the package or repository history inspected during the initial
audit. The removed TinyXML sources carried their own upstream notices and are
no longer distributed by this package.

The package metadata is therefore recorded, but the right to apply
Apache-2.0 to every inherited SemaFORR source file cannot be established from
the repository alone. A maintainer with access to the original contribution
records must confirm provenance before public redistribution. This audit does
not relicense inherited code or treat the manifest declaration as proof of
ownership.
